# Generierte Projektmedien

Beide Bilder wurden mit der eingebauten Bildgenerierung erstellt und anschließend als lokale Projektdateien unter `assets/` gespeichert. Es wurde kein CLI-/API-Fallback verwendet.

## `assets/home-banner-v1.png`

```text
Use case: stylized-concept
Asset type: responsive game home menu banner
Primary request: an original high-energy anime-inspired party-game key visual for a character voting and tournament app
Scene/backdrop: a neon-lit abstract arena with magenta and violet energy arcs, subtle bracket lines and confetti-like sparks
Subject: a diverse ensemble of four completely original stylized animated competitors shown as dynamic silhouettes and partial portraits, expressive but not resembling any known copyrighted character
Style/medium: polished premium anime-inspired digital illustration, cinematic game key art
Composition/framing: very wide landscape banner, characters distributed across the outer thirds, calmer dark negative space in the center for UI copy, safe crop for both desktop and mobile
Lighting/mood: electric, celebratory, competitive
Color palette: near-black, deep violet, magenta, coral red, small gold highlights
Constraints: no text, no letters, no logos, no watermark, no recognizable existing anime characters, no UI mockup, important faces and silhouettes must survive a centered mobile crop
```

## `assets/app-background-v1.png`
